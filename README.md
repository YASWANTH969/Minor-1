# Sri Rama Temple Website — Basireddy Palli

A responsive, static temple website built with plain HTML, CSS and JavaScript.

## Run in VS Code

1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. No Node.js, Python or database is required for the demo.

## Main files

- `index.html` — website structure/content
- `style.css` — responsive design
- `script.js` — navigation, year and enquiry demo

## Before publishing

Replace these placeholders with official information from the temple committee:

- Temple photographs in the Gallery
- Official phone number
- Official darshan/pooja timings
- Confirmed Google Maps location
- Official UPI ID / bank details
- Actual festival dates
- Temple committee social-media links
